# Installing Patti Back Office on a Laptop or Phone

Patti Back Office can be installed as an app on a laptop/desktop browser or added to a phone's
home screen, once it's running at its deployed Render URL. This is the same website — installing
it just gives it its own window/icon instead of living inside a browser tab. It still needs an
internet connection to work; nothing is available offline in this version.

## Install on a laptop/desktop browser (Chrome, Edge, or similar)

1. Open the app's Render URL in the browser.
2. Log in normally.
3. Look for an **install icon** in the address bar (usually a small monitor-with-arrow icon on
   the right side of the address bar), or open the browser's **⋮** menu and look for **"Install
   Patti Back Office…"** / **"Install app"**.
4. Click it, then confirm **Install**.
5. The app opens in its own window and an icon is added to your desktop / Start menu / Applications
   folder, depending on your operating system. Launching it from there opens it the same way from
   then on — no browser address bar, just the app.

If you don't see an install option, the site may not have fully loaded yet — refresh once and
check again, or use the ⋮ menu method above instead of waiting for the icon.

## Add to a phone's home screen

**iPhone (Safari):**
1. Open the app's Render URL in Safari (must be Safari, not Chrome, for this to work on iPhone).
2. Log in normally.
3. Tap the **Share** button (square with an arrow pointing up).
4. Scroll down and tap **Add to Home Screen**.
5. Confirm the name ("Patti") and tap **Add**.
6. A "Patti" icon appears on the home screen; tapping it opens the app full-screen, without
   Safari's address bar.

**Android (Chrome):**
1. Open the app's Render URL in Chrome.
2. Log in normally.
3. Tap the **⋮** menu in the top right.
4. Tap **Add to Home screen** (or **Install app**, if Chrome offers it directly).
5. Confirm the name and tap **Add** / **Install**.
6. A "Patti" icon appears on the home screen; tapping it opens the app in its own window.

## Removing or reinstalling (useful while this is still a prototype)

Since this is still being tested and will change, you may occasionally want to remove and
reinstall it to make sure you're seeing the latest version.

**To remove:**
- **Desktop:** right-click the app's icon (Start menu, dock, or desktop) and choose
  **Uninstall**, or open the app, click the **⋮** menu inside its window, and choose
  **Uninstall Patti Back Office…**.
- **iPhone:** press and hold the "Patti" icon on the home screen, then tap **Remove App** /
  **Delete App**.
- **Android:** press and hold the "Patti" icon, then drag to **Uninstall** or tap the
  **Uninstall** option that appears.

**To reinstall:** just repeat the install steps above from the Render URL.

**If the app looks out of date after reinstalling:** the app checks for a fresh version of its
own screens and code every time it's opened while online, so a simple close-and-reopen (or a
manual refresh) is usually enough — a full uninstall/reinstall shouldn't normally be necessary
just to pick up a content update. Reinstalling is mainly useful if the icon or install itself
seems broken, not for routine updates.

## What this does and doesn't do

- Installing does **not** enable offline use. You still need an internet connection to log in,
  view data, or do anything — this only changes how the app opens (its own window/icon instead
  of a browser tab).
- No inventory, product, vendor, order, or receipt data is stored on the device by installing the
  app. Only the app's own screens/code are set up to load quickly; your actual business data
  always comes fresh from the server each time.
