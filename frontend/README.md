# Patti Back Office — Frontend

React + Vite + TypeScript frontend for the Patti Back Office MVP.

See the [repository root README](../README.md) for local setup, environment variables, Supabase
configuration, and the manual acceptance checklist.

```bash
npm install
cp .env.example .env   # fill in VITE_API_BASE_URL / VITE_SUPABASE_URL / VITE_SUPABASE_ANON_KEY
npm run dev
```
